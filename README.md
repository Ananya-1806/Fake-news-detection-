# Fake-news-detection-
Fake News Detection using Natural Language Processing and Machine Learning.

# Project Overview
Fake News Detection is a machine learning and Natural Language Processing (NLP) project designed to classify news articles as real or fake. The project applies text preprocessing and feature extraction techniques to convert news content into numerical features and then uses machine learning algorithms to make predictions.

# Objectives
- Detect whether a news article is real or fake.
- Apply Natural Language Processing techniques to news text.
- Clean and preprocess textual data.
- Convert text into numerical features using TF-IDF.
- Train and compare different machine learning models.
  
# Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
  
# Feature Extraction
- TF-IDF (Term Frequency–Inverse Document Frequency)
  
# Machine Learning Algorithms
The following algorithms were used:
- Logistic Regression
- Multinomial Naive Bayes
- Passive Aggressive Classifier
  
# Project Workflow
1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Text Tokenization
5. Stop-word Removal
6. Lemmatization
7. TF-IDF Feature Extraction
8. Train-Test Split
9. Model Training
10. Model Evaluation
11. Fake/Real News Prediction

# Dataset
The project uses news datasets containing real and fake news articles.
The datasets were combined and preprocessed before training the machine learning models.

# Model Evaluation
The models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
